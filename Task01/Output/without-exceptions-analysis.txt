COMPARISON: EXCEPTIONS VS ERROR CODES

1. Exception Handling:
- Uses try, catch, throw and finally.
- Provides meaningful exception messages.
- Useful for handling unexpected failures.
- Throwing exceptions has additional runtime overhead.

2. Error Code Handling:
- Uses return values such as 0, -1, -2 and -3.
- Does not throw custom exceptions.
- Requires manual checking of return values.
- Can be simpler and faster for routine validation failures.

TIME AND SPACE COMPLEXITY

Time Complexity: O(1)
Space Complexity: O(1)

Both implementations perform a fixed number of validation checks and use a constant amount of extra space.

CONCLUSION:
Exception handling improves error reporting and separates error-handling logic from normal execution. Error codes avoid exception creation and are useful for expected validation failures.
