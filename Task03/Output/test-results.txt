COMPARISON:
1. Manual approach requires explicit close() calls.
2. Try-with-resources closes resources automatically.
3. Both approaches handle IOException.
4. Try-with-resources is cleaner and safer.

RESOURCE CLOSING:
Resources are closed in reverse order of creation in try-with-resources.
If closing throws an exception while another exception is active, the closing exception is suppressed.

COMPLEXITY:
Time: O(n), where n is the number of input records.
Auxiliary space: O(1), excluding buffered I/O storage.

CONCLUSION:
Try-with-resources reduces resource leaks and simplifies file handling.
